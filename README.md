# -# Название проекта
RSA: демонстрация уязвимостей.
## Описание
Программа которая демонтрирует генерацию сильных ключей а так же то как происходяь те или иные атаки.
## Что демонстрирует
Атаку по общему множетелю, атаку Ферма и атаку при малом показателе е
## Запуск
Что бы запустить программу сохраните код у себя на устройстве и откройте в
интерпретаторе. Затем запустите , в консоли появится меню.
## Структура
Меню предалагает 7 вариантов:
1. Сгенерировать безопасный RSA
2. Сгенерировать слабый RSA для Ферма
3. Сгенерировать две пары с общим множителем
4. Запустить атаку Ферма
5. Запустить атаку общего множителя
6. Запустить атаку при малом e
7. Шифрование и расшифрование
!ВСЕ ОНИ ЛИШЬ ДЕМОНСТРАЦИЯ!
