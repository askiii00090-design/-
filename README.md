## 🎯 Цель проекта
Исследование теоретических основ асимметричного алгоритма шифрования RSA и практическая демонстрация снижения его криптостойкости при некорректном выборе параметров генерации ключей.

---

## 📖 Краткое описание RSA
**RSA** — асимметричный алгоритм шифрования, основанный на сложности факторизации больших чисел. Основная формула модуля: `n = p × q`.

*   **Открытый ключ (`e`, `n`):** Используется для шифрования данных.
*   **Закрытый ключ (`d`, `n`):** Используется для расшифровки. Вычисляется с помощью секретных простых чисел `p` и `q`.

---

## ⚔️ Реализованные атаки на RSA в проекте

Программа наглядно показывает, как ломается алгоритм, если ключи созданы неправильно:

1. **Атака Ферма:** Срабатывает, если простые числа `p` и `q` находятся слишком близко друг к другу. Модуль `n` быстро раскладывается на множители через разность квадратов.
2. **Атака с общим множителем:** Срабатывает, если два разных ключа используют одно и то же число `p`. Общий делитель мгновенно находится через функцию `gcd`.
3. **Атака с малым `e`:** Срабатывает, если открытый показатель `e` слишком мал (например, равен 3) и само сообщение небольшое. Текст восстанавливается простым извлечением корня.
